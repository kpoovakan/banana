# Banana
A quickstart guide to obtaining radiation resources, free of charge.
<img src="thumbnail.gif" alt="decorative banana animation" />

### Try It
Open [Banana](https://kpoovakan.github.io/banana) in your browser. Requires internet connection.

### What Is This??
This is a quickstart guide to obtaining radiation resources, free of charge! As in, the quickstart guide is free. The radiation resource isn't.

### Tech Stack
HTML, CSS, and some images. All frontend, and <i>no JavaScript</i>. This project still has interactive features, thanks to some clever CSS!

### Why No JavaScript?
JavaScript is my most used language. Over the past few weeks, the amount of time I spent writing JavaScript was more than triple the amount of time I spent writing HTML or CSS. This project is a fun challenge, to create an interactive project JavaScript-free!

### Running Locally
Clone this repository:
```git clone https://github.com/kpoovakan/banana.git```  
Then, open index.html
